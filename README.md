# Procket Homebrew tap

```sh
brew install procket-dev/tap/procket
procket setup
```

[Procket](https://procket.dev) records the prompts behind your commits. This tap
is updated automatically with each release; see the
[install guide](https://procket.dev/install) for other ways to install.
